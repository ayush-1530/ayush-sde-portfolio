# Organisation logo sources

Local assets used in the overview and professional journey sections:

- `zindagi.png`: [Zindagi Technologies official icon](https://zindagitech.com/apple-touch-icon.png).
- `nic.svg`: [NIC UXDT official square logo](https://www.uxdt.nic.in/wp-content/themes/understrap-child/img/footer-nic-logo.svg), also shown in the [NIC logo collection](https://www.uxdt.nic.in/documents/logos/nic-logo/).
- `drdo.png`: [Public mirror of the DRDO emblem](https://media.9curry.com/uploads/organization/image/183/drdo-logo.png), matching the supplied reference. The official DRDO image server was unavailable during this update.

Brand artwork and colours are preserved. Logos are displayed with `object-fit: contain` on a white badge for legibility in both themes.
